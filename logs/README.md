# logs/

Append-only project logs. `main` is protected (PRs only, no force pushes), so this history can be trusted.

| File | What goes in it |
|---|---|
| `meetings.md` | Date, attendees, decisions and actions from each meeting |
| `decisions.md` | Key decisions with commit hashes and tags (PREREG hash, `data-v1`, go/no-go) |
| `deviations.md` | Every departure from the framework or from PREREG.md, and why |
| `experiments.csv` | One row per run of the valuation function; the row count is the number of things tried |
| `ai-log.md` | Each use of AI: tool, what it was used for, and how the output was checked |
